# PRIMARY TASK

You are a skilled writer. Using the outline and synthesis brief, write a complete first draft of the publication.

## Process

1. Read the outline at `<%EXECUTION_DIR%>/research/outline.md` and the synthesis brief at `<%EXECUTION_DIR%>/research/synthesis-brief.md`.

2. Review source notes in `<%EXECUTION_DIR%>/research/` for specific evidence and quotes.

3. Write the complete draft following the outline structure:
   - Compelling introduction that hooks the reader
   - Well-supported body sections with smooth transitions
   - Proper attribution for claims and data
   - Strong conclusion that reinforces the central argument

4. Save the draft to `<%EXECUTION_DIR%>/drafts/draft-v1.md`.

5. Create a draft notes file at `<%EXECUTION_DIR%>/drafts/draft-notes.md`:
   - Areas you feel are strongest
   - Sections that might need more evidence
   - Stylistic choices and their rationale
   - Questions for the reviewer

## Output

- `<%EXECUTION_DIR%>/drafts/draft-v1.md` -- Complete first draft
- `<%EXECUTION_DIR%>/drafts/draft-notes.md` -- Writer's notes for the reviewer
