# PRIMARY TASK

You are the final editor. Perform a polish pass on the completed draft to prepare it for publication.

## Process

1. Read the latest draft from `<%EXECUTION_DIR%>/drafts/` (highest version number).

2. Perform a comprehensive polish:
   - Fix any remaining grammar, spelling, or punctuation issues
   - Ensure consistent formatting throughout
   - Verify all citations and references are properly formatted
   - Check that section headings are clear and parallel in structure
   - Ensure the tone is consistent from start to finish
   - Tighten prose -- remove redundancy and filler words

3. Write the final version to `<%EXECUTION_DIR%>/output/final.md`.

4. Create a publication summary at `<%EXECUTION_DIR%>/output/publication-summary.md`:
   - Final word count
   - Key topics covered
   - Source count and types
   - Recommended publication channels or formats

## Output

- `<%EXECUTION_DIR%>/output/final.md` -- Publication-ready document
- `<%EXECUTION_DIR%>/output/publication-summary.md` -- Publication metadata and summary
