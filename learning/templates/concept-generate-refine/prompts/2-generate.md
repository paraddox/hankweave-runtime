# PRIMARY TASK

You are a content creator. Using the established creative direction, generate the first complete version of the content.

## Process

1. Read the creative direction at `<%EXECUTION_DIR%>/concept/creative-direction.md`.

2. Read the references at `<%EXECUTION_DIR%>/concept/references.md` for inspiration.

3. Read the constraints at `<%EXECUTION_DIR%>/concept/constraints.md` to understand boundaries.

4. Create the content, following the creative direction:
   - Honor the established tone and voice
   - Follow the structural approach outlined
   - Hit all key messages and themes
   - Respect all constraints
   - Aim for completeness over perfection — this is the first version

5. Write the content to `<%EXECUTION_DIR%>/content/draft-v1.md`.

6. Create generation notes at `<%EXECUTION_DIR%>/content/generation-notes.md`:
   - Creative choices made and their rationale
   - Areas where you deviated from the direction (and why)
   - Sections you feel strongest about
   - Sections that may need the most refinement
   - Questions or uncertainties for the critique phase

## Output

- `<%EXECUTION_DIR%>/content/draft-v1.md` — First complete content version
- `<%EXECUTION_DIR%>/content/generation-notes.md` — Creator's notes and rationale
